
# 🎵 Music Alarm App

A simple offline music player and alarm app for Android. Play your favorite songs, wake up to your own music, and fall asleep with a sleep timer.

## ✨ Features

- 🎵 **Music Player** – Browse and play music from folders on your device.
- ⏰ **Music Alarms** – Set alarms and choose any song from your music library.
- 😴 **Sleep Timer** – Automatically stop music after a set amount of time.
- 🔁 **Repeat & Snooze** – Schedule one-time or daily alarms and snooze when you need a few extra minutes.
- 🎨 **Dark Mode** – Switch to a dark theme for a more comfortable experience.

**Fully offline. No internet connection required.**

## 📥 Download & Install

1. Visit the [Releases Page](https://github.com/anjalraitmg/music_alarm_app/releases).
2. Open the latest release.
3. Download the `.apk` file compatible with your device (e.g. `app-arm64-v8a-release.apk`).
4. Open the downloaded file and install the app.
5. If prompted, allow installation from this source.

That's it! Open the app and enjoy. 🎉

## 🛠️ Build from Source

Want to build the app yourself? Make sure you have [Flutter](https://flutter.dev/) installed.

Clone the repository:

```bash
git clone https://github.com/anjalraitmg/music_alarm_app.git
cd music_alarm_app
```

Install dependencies:

```bash
flutter pub get
```

Run the app on a connected Android device:

```bash
flutter run
```
